# PinShot MCP 当前能力与实测记录

更新日期：2026-10-19。本文补充 README 和早期验收记录；早期文档中“只读预览”“仅十个工具”等描述属于历史阶段，不代表当前接口。

## 当前工具

当前暴露 15 个工具：

- 连接与状态：`ping`、`get_state`。
- 捕获：`list_windows`、`capture_screen`、`capture_window`。
- 标注：`add_annotation`、`remove_annotation`。
- 编辑：`edit_session`、`undo_session`、`redo_session`。
- 输出：`preview_session`、`save_session`。
- 会话窗口：`show_session`、`hide_session`、`close_session`。

截图使用运行中的 Rust PinShot 原生捕获链；Node 服务负责 MCP 协议。程序须以 `--automation` 启动。

## 图片读取与坐标

截图和预览直接返回 MCP PNG 图片内容，不只是文件路径，AI 可以读取返回的画面。预览长边最多 1600 像素，响应附带 `preview.width`、`preview.height`、`preview.scale`。

标注坐标始终使用原图像素：`原图坐标 = 预览坐标 / preview.scale`。全屏截图的 `origin` 可能为负数；图片内标注仍以图片左上角为原点，不直接使用桌面绝对坐标。保存输出与缩略预览分开，正常保存保留原图尺寸。

指定窗口时先调用 `list_windows`，再以窗口标题关键字调用 `capture_window`。默认尝试激活窗口，返回 `window.activated`；关闭激活时，被其他窗口遮挡的区域可能捕获到上层画面。

## 编辑与会话

`edit_session` 打开原生工具栏，允许用户继续手工编辑。窗口编辑结果同步到会话状态、预览及导出；未完成的操作会通过 busy 状态阻止 AI 覆盖。标注使用稳定 ID，窗口内编辑与 AI 修改共享撤销历史。隐藏窗口保留会话，再次显示可继续使用。

在后台会话中先添加标注、之后才打开编辑窗口时，这些已有标注是窗口初始内容，不能据此断言存在可撤销历史。应在编辑窗口建立后新增标注，再验证撤销和重做。

最多保留四个会话。仅关闭自己建立的测试会话，不清理用户已有会话。保存必须指定绝对 PNG 路径，父目录需要存在，不能覆盖已有文件。

## 本机实测

2026-10-19，通过 Codex 实际调用 MCP，验证：

- 全屏捕获成功：4160 × 1400，返回 1600 × 538 预览，可读取双屏画面。
- 窗口枚举和 ChatGPT 单窗口捕获成功：1662 × 1190。
- 添加矩形、箭头、文字、椭圆成功，返回图片中标注可见。
- 编辑窗口建立后新增椭圆；撤销使标注从 4 个变为 3 个，重做恢复到 4 个，ID 保持不变。
- 删除标注、隐藏与重新显示窗口、保存 PNG、关闭会话成功。
- PinShot 首选项窗口捕获成功：542 × 442，能够读取常规页内容。
- 测试未修改原有会话。全屏和单窗口功能测试会话结束后已关闭；另一次首选项查看会话不计入该清理记录。

本轮没有模拟手工鼠标绘制、拖动与文字输入，因此不将手工编辑双向同步记作已通过实测；也不代表全部 Rust 构建或 CI 已验证。

## 截图与桌面控制的区别

PinShot MCP 提供截图、会话与标注操作，不提供通用桌面鼠标点击或键盘输入。能够看到设置页，不代表可以点击该页的控件。

Computer Use 是独立连接。本轮会话的工具明确标注原生电脑 API 被禁用，仅可访问浏览器；不能通过添加截图权限或修改 PinShot 参数启用它。应用列表为空本身不足以证明未授权。

Windows Computer Use 的应用访问、前台桌面要求及授权提示以客户端和[官方说明](https://learn.chatgpt.com/docs/computer-use)为准。不要以“完全访问”代替桌面控制授权，也不要通过修改本地白名单绕过宿主禁用的能力。

## 尚未覆盖

OCR、翻译、通用桌面操作和设置控件控制尚未作为本组 MCP 工具提供。历史验收文档保留作为阶段记录，新增能力需分别补充测试证据。
